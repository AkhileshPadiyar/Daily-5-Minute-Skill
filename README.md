# Daily 5-Minute Skills 🧠

A simple Flask app that shows a new skill every day to help you grow in 5 minutes or less.

## Setup Instructions

1. Clone the repo:
   ```
   git clone https://github.com/yourusername/daily-5min-skills.git
   cd daily-5min-skills
   ```

2. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

3. Run the app locally:
   ```
   python app.py
   ```

4. Visit: `http://127.0.0.1:5000/`

## Deployment

- This app can be deployed easily to **Render**, **Railway**, or **Heroku**.
- Supports GitHub integration out of the box.
